# Examples

This directory contains example scripts demonstrating the usage of MLModelSelect.

## Quick Start
```bash
python quickstart.py
```
A simple introduction to MLModelSelect using the Iris dataset.

## Classification Example
```bash
python classification_example.py
```
Demonstrates multi-class classification with 7 different models on a synthetic dataset.

## Regression Example
```bash
python regression_example.py
```
Demonstrates regression with 9 different models comparing various algorithms.

## Clustering Example
```bash
python clustering_example.py
```
Demonstrates clustering comparison with different algorithms and parameters.

## Complete Demo
```bash
python complete_demo.py
```
Comprehensive showcase of all MLModelSelect features including:
- Classification with 5+ models
- Regression with 5+ models
- Clustering with 4+ models
- Individual model usage examples
- Complete summary

## Requirements

Make sure you have installed the dependencies:
```bash
pip install -r ../requirements.txt
```

Or install the package in development mode:
```bash
cd ..
pip install -e .
```
